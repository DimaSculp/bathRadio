# План MVP

**Статус: готово (2026-11-17).** Голосом через Алису и по IP переключаются режимы **радио** / **блютуз** на Feather HUZZAH; звука пока нет.

## Критерий готовности

1. HA открывается на `http://localhost:8123` — сделано
2. ESP в Wi‑Fi 2.4 и видна в HA (ESPHome) — сделано
3. На `http://<IP>/` есть раздел режимов; смена с телефона/ПК работает — сделано
4. Команды Алисе меняют тот же статус — сделано
5. Режимы взаимоисключающие — сделано

## Что сработало

- Docker Compose: Home Assistant + ESPHome на ноутбуке
- Прошивка `toilet-radio` (Feather HUZZAH, COM11)
- Веб UI «Динамик / радио»
- ESPHome → HA → Yandex Smart Home → УДЯ / Алиса

## Вне MVP (дальше)

- Регулятор громкости **1–10** в веб UI (и на железе)
- Плата с Classic Bluetooth (ESP32) + A2DP sink
- SD + I2S‑усилитель + водозащищённый динамик
- Корпус 3D
- Перенос HA на постоянный хост — см. [ha-migration.md](ha-migration.md)
