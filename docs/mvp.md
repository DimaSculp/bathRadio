# План MVP

Цель: голосом или по IP переключать режимы **радио** / **блютуз** на Feather HUZZAH; звука пока нет.

## Критерий готовности

1. HA открывается на `http://localhost:8123`
2. ESP в Wi‑Fi 2.4 и видна в HA (ESPHome)
3. На `http://<IP>/` есть раздел режимов; смена с телефона/ПК работает
4. Команды Алисе меняют тот же статус
5. Режимы взаимоисключающие

## Шаги

1. Docker Compose: Home Assistant + ESPHome
2. Прошивка `toilet-radio` по USB (COM11)
3. Веб UI режимов на плате
4. Интеграция ESPHome в HA
5. Yandex Smart Home → УДЯ → проверка голосом

## Вне MVP

- Регулятор громкости **1–10** в веб UI (и позже на железе / усилителе)
- SD, I2S, динамик
- A2DP на ESP32 (реальный Bluetooth)
- Корпус 3D
- Перенос HA на постоянный хост
