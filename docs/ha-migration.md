# Перенос Home Assistant с ноутбука

Сейчас HA крутится в Docker на ПК. Это временно: пока ноут спит или выключен, Алиса до bathRadio через HA не достучится.

## Чем заменить ноутбук

Любой всегда включённый хост в той же домашней сети:

| Вариант | Комментарий |
| --- | --- |
| Mini PC / старый ноут | Docker Compose как сейчас, самый простой перенос |
| Raspberry Pi 4/5 (4 GB+) | HA OS или Docker; удобно «поставить и забыть» |
| Home Assistant Green / Yellow | Официальные коробки, меньше возни с ОС |
| NAS (Synology и т.п.) | Если уже есть и умеет Docker |
| N100 / Beelink и аналоги | Тихий мини‑ПК под 24/7 |

Не нужен мощный ПК: для пары ESP и УДЯ хватает слабого железа с стабильным питанием и Ethernet (лучше, чем только Wi‑Fi).

## Можно ли «залить» текущую установку без пересоздания?

**Да.** Полностью заново настраивать Алису и устройства не нужно, если сделать backup → restore.

1. В текущем HA: **Настройки → Система → Резервные копии → Создать копию** (полный backup).
2. На новом устройстве поставь HA (HA OS или тот же `docker compose` из репозитория).
3. При первом запуске или в меню бэкапов: **Восстановить** этот архив.
4. Проверь, что ESP снова online (тот же IP/API key в `secrets` на стороне платы; в HA сущности подтянутся из бэкапа).
5. УДЯ / Yandex Smart Home обычно оживают вместе с конфигом; если устройства пропали в приложении Алисы — один раз обнови список устройств.

Альтернатива Docker: скопируй том `homeassistant/config/` на новый хост и подними тот же `docker-compose.yml` — по сути тот же перенос данных.

Папку `esphome/` с `toilet-radio.yaml` тоже перенеси; `secrets.yaml` копируй вручную (в git его нет).
